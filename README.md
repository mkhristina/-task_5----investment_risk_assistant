# Инвестиционный комитет — система оценки рисков проектов

Проект предназначен для анализа инвестиционных проектов и оценки их рисков с помощью нечёткой логики и машинного обучения.

## Возможности

- Генерация и очистка данных об инвестиционных проектах.
- Анализ данных и построение графиков.
- Оценка финансового, рыночного и организационного рисков.
- Классификация проектов на низкий, средний и высокий риск.
- Сравнение моделей машинного обучения.
- Объяснение предсказаний с помощью SHAP.
- Анализ сценариев What-if и моделирование Monte Carlo.
- Интерактивный дашборд на Streamlit.
- Создание отчётов в PDF и Excel.

## Используемые технологии

Python, Pandas, NumPy, Scikit-learn, scikit-fuzzy, Optuna, SHAP, Streamlit, Matplotlib и Seaborn.

## Структура проекта

## Структура проекта

- `data_generator.py` — генерация синтетических данных.
- `data_cleaner.py` — очистка данных и обработка пропусков и выбросов.
- `eda.py` — разведочный анализ и визуализация данных.
- `fuzzy_model.py` — нечёткая оценка инвестиционных рисков.
- `ml_model.py` — обучение, сравнение и выбор модели машинного обучения.
- `explainer.py` — интерпретация предсказаний с помощью SHAP.
- `whatif_mc.py` — анализ сценариев What-if и моделирование Monte Carlo.
- `dashboard.py` — интерактивный веб-интерфейс на Streamlit.
- `report_generator.py` — формирование PDF- и Excel-отчётов.
- `business_logic.py` — анализ классификационных ошибок и бизнес-потерь.
- `main.py` — консольное меню для запуска функций проекта.
- `requirements.txt` — список необходимых Python-библиотек.
- `README.md` — описание проекта и инструкция по запуску.

### Основные каталоги

- `data/` — исходные, очищенные данные и результаты обработки.
- `models/` — сохранённая обученная модель.
- `reports/` — графики, таблицы и сформированные отчёты.
- `.venv/` — виртуальное окружение Python.



## Установка и запуск

Создай виртуальное окружение и установи зависимости:

```bash
python -m venv .venv
```

Для Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

```bash
python -m pip install -r requirements.txt
```

Запуск проекта:

```bash
python main.py
```

Запуск веб-интерфейса:

```bash
streamlit run dashboard.py
```

## Данные и результаты

Проект использует 2 000 синтетических записей об инвестиционных проектах. Результаты обработки, обученная модель, графики и отчёты сохраняются в каталогах `data/`, `models/` и `reports/`.

**Примечание:** проект является учебным прототипом. Для применения в реальных инвестиционных решениях необходима дополнительная проверка на реальных данных.
